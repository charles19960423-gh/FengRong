关于手册

📖 项目开发手册

这份手册将我们沟通的所有细节（从视觉逻辑、代码实现到线下运营闭环）整合为一套可落地的技术与运营白皮书。

🎯 项目定位

基于"办公室酒馆"场景，连接传媒行业供需的沉浸式 RPG 增长引擎。

🎨 视觉灵魂规范

元素 设计规范 心理暗喻
主色调 枫红(#8C2B1B)、榕黑(#1A120B)、古金(#D4AF37) 沉稳、热血、江湖感
背景质感 深色木纹、皮革、牛皮纸 吧台与卷轴的物理触感
法器特效 动态白烟粒子、银色大力胶补丁 职业认同感、实战磨损感
交互动效 物理撞击感的火漆盖章、引信燃烧 承诺的重量、紧迫感

📅 开发路线图 (MVP Roadmap)

第一阶段 (1-2周)
前端静态页 + 拟物化 CSS 样式 + 微信登录逻辑
第二阶段 (3-4周)
后端声望与任务流数据库、过热/磨损逻辑计算引擎
第三阶段 (5周+)
Canvas 生成长图分享功能、线下核销管理后台

💡 给馆主的特别建议

这套系统最强的不是代码，而是"身份阶层"。

  • 元老 ID 必须在内测群里高调发放，制造稀缺感。
  • 金属刻印的声音 必须在酒馆人多的时候响起，制造围观。
  • 3号桌的特权 必须真实兑现，让普通用户感受到"声望"的力量。
